# Données audio d'évaluation

Pour le pilote PFE, limiter les enregistrements aux données nécessaires à l'évaluation. Informer les participants de l'usage des enregistrements et éviter d'inclure des informations personnelles inutiles dans les phrases de test.

Les fichiers audio du corpus local sont ignorés par Git afin de ne pas publier automatiquement les voix des participants dans le dépôt. Les résultats agrégés (WER, latence, RTF) peuvent être reportés dans le mémoire sans publier les fichiers audio bruts.
