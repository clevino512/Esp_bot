# Phase ASR — état du code

La partie logicielle préparatoire est maintenant en place sur la branche PFE : sélection tiny/base/medium, cache des modèles, métadonnées de performance, WER, benchmark reproductible, validation audio, tests et documentation.

La phase n'est pas déclarée expérimentalement terminée tant que les tests n'ont pas été exécutés sur l'environnement réel et que le corpus audio n'a pas produit les mesures tiny/base/medium.
