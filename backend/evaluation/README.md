# Évaluations PFE UniBot ESPA

Ce dossier centralise les protocoles et résultats expérimentaux du PFE.

- `README_ASR.md` : protocole de comparaison Whisper.
- `asr_corpus.csv` : manifeste du corpus à remplacer par les vrais enregistrements.
- `ASR_TEST_SENTENCES.md` : phrases initiales proposées pour constituer le corpus oral.
- `RESULTS_TEMPLATE.md` : tableau de résultats à remplir uniquement avec les mesures réelles.
- `results/` : sorties JSON produites par les scripts d'évaluation.

Les résultats expérimentaux doivent rester traçables et reproductibles : même corpus pour les modèles comparés, conservation des transcriptions de référence et absence de valeurs inventées.
