# Notes pour la rédaction du mémoire — ASR

La section ASR pourra décrire :

- l'intégration de Whisper comme moteur principal de reconnaissance vocale ;
- l'utilisation de trois variantes (`tiny`, `base`, `medium`) soumises au même corpus français ;
- le WER comme métrique de fidélité de transcription ;
- la latence et le Real-Time Factor comme indicateurs de performance ;
- la sélection finale du modèle comme compromis entre précision et coût de calcul ;
- Vosk conservé comme piste/mode alternatif hors-ligne dans l'architecture.

Les tableaux numériques et la conclusion sur le meilleur compromis devront être complétés après le benchmark réel.
