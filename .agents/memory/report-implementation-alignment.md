---
name: Report and implementation alignment
description: Cohérence entre le périmètre annoncé dans le mémoire et les fonctions réellement validées
---

Le mémoire doit distinguer clairement ce qui est implémenté, ce qui est mesuré et ce qui reste une perspective. Une architecture ou un protocole proposé ne doit pas être présenté comme un résultat expérimental.

**Why:** Le rapport actuel décrit une méthode d’évaluation RAG et plusieurs fonctionnalités PFE, mais ne fournit pas encore de résultats chiffrés suffisants pour chacune d’elles.

**How to apply:** Avant une soutenance, aligner les modèles, paramètres, fonctionnalités et métriques du texte avec la configuration réelle du projet, puis ajouter les résultats reproductibles, les limites et les preuves de validation utilisateur.
